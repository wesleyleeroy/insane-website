---

When testing the local website at http://localhost:3000:

// turbo-all

1. Open the browser to http://localhost:3000
2. Perform any necessary scrolling, clicking, or mouse movements
3. Capture screenshots as needed
4. Execute JavaScript for debugging when required

All browser subagent steps should use SafeToAutoRun: true since we're testing our own local development server.
